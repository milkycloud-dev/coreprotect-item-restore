# Changelog

## 1.0.0 (2026-11-02)

First public release.

- `decode`: CoreProtect `co_container` rows (TSV with hex meta) to JSON, Java serialization and embedded gzipped NBT unpacked, NBT number types kept.
- `commands`: armor stand `item replace` commands that fill only empty slots, or `/give` commands, with damage, enchantments, repair cost, custom data, attribute modifiers and mod components.
- `--namespaces` maps Bukkit modded material names back to mod item ids.
- Unit tests.
